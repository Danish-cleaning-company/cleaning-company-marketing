# Kolding Rengøring Next.js Foundation

Static-export Next.js foundation for the incremental migration of the existing Kolding Rengøring website.

## Commands

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```

`npm run build` generates the static site in `out/`.

See `MIGRATION_NOTES.md` before changing routes, canonical URLs, or integrations.
